# Orientation video scripts (one per app, 8 minutes each)

Design §5 says each app's orientation video is the same length and style, shows only general navigation, and no task
step. Both videos follow the same outline, with the same timings, recorded by the same narrator on the reference
configuration, with neutral wording. A reviewer checks both before the binding freeze. Neither may show anything a
card asks for:
- no contrast setting, slab or projection;
- no 3D, clipping or picking;
- no points, shapes or label editing;
- no segmentation, measurement, animation or Python;
- no saving, recovery, packages or updates.

| Time | Segment (identical for both apps) |
| --- | --- |
| 0:00–0:45 | What the program is for, in one sentence; opening it |
| 0:45–2:30 | The main window: where data appear, where the list of open data is, where settings for the selected data are, where help is |
| 2:30–4:30 | Opening one 2D image of a different kind from any task (a brightfield RGB photo), then panning and zooming it with the mouse |
| 4:30–6:00 | Showing and hiding one open image; selecting it |
| 6:00–7:15 | Where the program's own help and documentation are |
| 7:15–8:00 | Closing the image and quitting the program |

The orientation image is the same file for both apps, and is not part of any task package.
