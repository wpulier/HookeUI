# Security reporting

This repository is public. Report a vulnerability privately through GitHub's
**Report a vulnerability** form (the repository's **Security** tab →
**Advisories**), never in a public issue, discussion or pull request.

Include affected revisions, reproduction, expected behavior and impact, with
synthetic reproduction data. Never include real credentials or private data,
even in a private report. Do not access other people's data or run destructive
tests. Ordinary bugs without sensitive details can use public issues.

The current source is a developer preview. No fixed response time or security
certification is promised. Maintainers assess reports and publish remediation
information when appropriate.
