# Security reporting

Do not post credentials, private data or exploit details in a public issue.
Use GitHub's **Security → Report a vulnerability** on this repository for private
reports. Include affected revisions, reproduction with synthetic data, expected
behavior and impact. Do not access other people's data or run destructive tests.

The current source is a developer preview. No fixed response time or security
certification is promised. Maintainers assess reports and publish remediation
information when appropriate. Ordinary bugs without sensitive details can use issues.
