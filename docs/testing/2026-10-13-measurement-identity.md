# Measurement result identity — 2026-10-13

Actions now describe evidence belonging to the executions their own ToolRun used, including explicit reuse. A slow non-measuring action cannot claim another request's newest population, and overlapping measuring actions retain their own results. The table link carries the source session and correction revision.

Both Measurements HTTP routes require `session` and `revision`. A read snapshots table metadata before its thread work, validates retained population inputs, and rechecks session generation, object identity, availability and correction revision before returning. Corrections and session changes produce a useful refusal instead of mixed rows. Masks and model weights are not copied for a table read. CSV stays the ordinary six-significant-figure table export; the native-pixel exchange bundle remains a separate export.

The Studio pins the selected index entry, checks response identity, aborts superseded reads and downloads, clears stale rows after a correction or session change, and offers reopening after refusal. Deep links wait for the first session handshake. Fiji results say particles and imported originals describe their own pixel calibration, preserving measured units and definitions.
