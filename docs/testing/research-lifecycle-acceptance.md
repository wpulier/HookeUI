# Research lifecycle acceptance procedure

This document defines checks, not a claim of qualification. Historical private
campaign records are not distributed with the core. All release qualification
requires evidence against the candidate source and its operating conditions.

| Behavior | Required observation |
|---|---|
| Workspace and feedback | Composer, thread and focus remain usable at desktop and mobile widths. |
| Delegation | Independent work consumes only the requested completed run and respects stop. |
| Revisions | Exact source selection survives Send; scientific and presentation revisions remain distinct. |
| Version navigation | Old and current versions reopen without new computation or spending. |
| Presentations | Data and caveats survive rendering; findings remain readable after producer failure. |
| Restart and concurrency | Duplicate IDs do not duplicate dispatch; competing output is retained; restart never silently redispatches. |
| Receipts | Unknown charges remain unknown; late usage reconciles once; cancellation never invents settlement. |
| Ownership | Sources, owning session and browser, capture labels and rendered acknowledgements remain consistent. |

Score correctness, source integrity, interaction clarity, window usability,
responsiveness and recovery separately. Require mean at least 8/10 and every
category at least 7/10, alongside all mandatory assertions. Wrong sources,
corrupted evidence, false completion, duplicate paid dispatch or lost work block
acceptance at any score. A model's self-rating is not browser evidence.

Predeclare representative inputs, expected outcomes, source digests, model and
effort, call limits, deadlines and spending limits before model-based checks.
Retain all failures. Separate synthetic regressions, real persistence, actual-model
qualification and browser observations. Reuse evidence only after checking source,
fixtures and operating conditions; rerun affected cases after changes.

Physical cameras, microphones, long acquisition and performance qualification are
separate checks. Concurrent test timings do not qualify interactive performance.
