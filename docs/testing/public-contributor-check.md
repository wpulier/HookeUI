# Public contributor check

Run a bounded check of production library behavior using generated images, masks,
recordings and journals. It requires no private recordings, provider accounts,
credentials or downloaded models.

On the supported Apple Silicon Mac setup, follow [first installation](../clean-start.md)
for prerequisites, then run from the repository root:

```sh
make setup
make check-public
```

Setup installs the locked Python and Studio packages and requires package-network
access. The check uses Python 3.13 and FFmpeg with its libx264 encoder; it does not
start the Studio, camera bridge or model workers. A missing prerequisite or failed
assertion fails the command. Pytest reports failures and skips; review any skip before
claiming the selected behavior was tested.

| Tests | What they verify |
| --- | --- |
| `test_starter_example.py` | The [three-particle generator](../../examples/three-particles/README.md), exact image/pixel hashes, provenance, corruption detection and overwrite refusal. |
| `test_measure.py` | Production measurements of known masks: shape, area, centroid, holes, scaling, overlap and large labels. |
| `test_evidence.py` | Atomic save, retained IDs and measurements after reopen, correction revisions and refusal of damaged or incomplete saves. |
| `test_corpus.py` | Generated eyepiece tours, decoded pixels against recorded truth, video resampling and annotation readers. |
| `test_sim_faults.py` | Camera-simulator degradation, repeat and pause/play behavior using generated bytes. |
| `test_public_check.py` | Fresh pytest collection rejects inherited asset locations and provider keys, while individual tests can supply their own synthetic data and keys. |

The test boundary creates new app, asset and catalog locations, disables account
Keychain access and selects a nonexistent keys file. It removes inherited credentials
for catalog services before test collection. Fixtures can then install synthetic
values. Model readiness is a stand-in in these tests; no model result is claimed.
The command disables automatic third-party pytest plugins and inherited pytest
selection options so its documented selection runs consistently.

This check supplies synthetic regression evidence. It does not qualify the real
Studio/Fiji journey, model inference, scientific accuracy, live hardware or performance.
The example's publication terms remain those recorded in its provenance.

`make check` remains the required integration gate: all Python/Studio tests, type
checks and the full non-cloud simulation suite. That suite has separate
footage and model requirements; `SIM_VIDEO` alone does not
remove them. Run affected regressions during development and retain failures, skips,
revision, tool versions and timing scope with each verification result.

The 2026-10-13 verification receipt, kept privately, records one measured run and its limits.
