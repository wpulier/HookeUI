# README screenshot

`hookeui-workspace.webp` is an unedited viewport capture of the running HookeUI
Studio, taken on October 27, 2026 at 1440 × 960 CSS pixels. Application source:
`d09a718830f9628853c6d91f6378c6d5385c22b3` (`dev`).

The capture uses a fresh local profile without provider credentials or personal
files. In the app, choose **Try the guided example → Find bright objects → See
measurements**. Close the Assistant and dismiss the walkthrough to show the image
and its measurements together. The measurements and outlines are actual outputs
of the local Bright objects method, not drawn or generated for the screenshot.
These are bright-region measurements, not biological ground truth.

The underlying microscopy image is **human_mitosis**, copyright David Root,
released under **CC0-1.0**. See [the image notice](../../assets/examples/NOTICE.md)
for the original source, paper and rights provenance. The screenshot's first-party
interface is covered by the repository's Apache-2.0 license; the CC0 image retains
its own terms. No official brand master assets are included.
