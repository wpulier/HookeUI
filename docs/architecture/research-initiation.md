# Research initiation and collaboration

Implementation milestone, 2026-11-01. Work remains on the research integration
branch above dev; no release or automatic merge. A passing unit test is not a
completed user journey or scientific qualification.

Project owns retained material and history; Study owns the question, plan and
assignments; WorkflowService owns scientific runs and attempts. A research plan
is retained Study state, not an executable document. Planning and saving start no
scientific work. Review pins the plan; exact workflow admission still checks
permissions, inputs, generations and resource readiness.

Assignments extend existing Study tasks. They identify the uncertainty, expected
output, evidence basis, dependencies, delegation reason and actual contributor.
An expired agent lease requires reconciliation, never automatic reassignment or
replaying an experiment. Connection identity, assignment identity and scientific
operation identity remain separate. A report is not human scientific acceptance.

The common journey is material → question → proposed plan → review → authorized
agent or manual execution → measured results → justified continuation. Connected
means authorized, not listening. External harnesses own model sessions. Hooke owns
shared assignments, evidence and admitted scientific execution. New capability
installations/activation require owner approval; sharing publicly is separate.

Instruction packages are pinned, non-executable guidance. They carry no access,
spending or runtime authority. Package text and Project evidence cannot override
host policy. Reuse catalog drafts, sandbox proofs, review and sharing rather than
create a second plugin installer.

Acceptance: fresh UI and connector initiation; two contributors continue from
retained evidence; no duplicate work after lost replies; useful output inspection;
microscopy reuse; bounded retrospective 2025 comparison; unchanged full checks.
The comparison allows six model sessions, two experiments per arm, at most two
model sessions concurrently and one heavy job. Each arm has a 60,000 input/output
token and 30 aggregate model-minute ceiling. All attempts count. No paid services,
contest upload or claim that the small comparison establishes swarm superiority.

Current capability-proposal slice retains exact package references and exposes owner review. Automated transfer into catalog draft preparation, sandbox proof, exact owner activation and rediscovery still require end-to-end qualification; a saved proposal alone does not pass that acceptance gate. Model allowances remain declarations until an external harness qualifies total input-plus-output accounting and stopping.
