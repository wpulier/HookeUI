Checking

Once, about 5 minutes. Keep the iPhone in your hand; this page ticks each step as it sees it done.

  1. Get the free Blackmagic Camera app

    On the iPhone, scan this code with the Camera app and tap the link: the App Store opens on Blackmagic Camera, by Blackmagic Design. Tap Get.

    Or search the App Store for “Blackmagic Camera”. It is free.

  2. Open it, and let this Mac reach it

    Open Blackmagic Camera. When it asks, allow the camera, the microphone and Local Network (that lets it talk to this Mac). Then tap the settings gear and turn on HTTP Server:

    SettingsNetwork AccessHTTP Server

    This ticks by itself once the Mac reaches the app. Keep the app open.

    Not ticking? Try these
    • The Mac can reach the app only while it is open and in front.
    • The iPhone must be on the same Wi-Fi as this Mac, or plugged into it with its cable.
    • Said no to Local Network? In the iPhone's Settings › Apps › Blackmagic Camera, turn Local Network on.
    • Turn off Remote Camera Control in Blackmagic Camera's settings, if it is on.
    • Don't have the app yet?

  3. Give it ObservationUI's settings

    Scan this code with the iPhone's Camera app and tap the link. Safari asks to download MicroscopeMind.xml: tap Download.

    The file goes to Downloads, in the Files app. Nothing else is installed.

    Then, in Blackmagic Camera, open:

    SettingsLive StreamPlatformImport Stream Settings

    and pick MicroscopeMind.xml from Downloads.

    Not ticking? Try these
    • The code opens nothing: the iPhone must be on the same Wi-Fi as this Mac.
    • Or get the file here and AirDrop it to the iPhone, then import it the same way.
    • Can't find it when importing? In the file picker, tap Browse, then Downloads.

  4. Choose the saved platform

    ObservationUI keeps the earlier MicroscopeMind platform name so existing phone settings keep working. Still in Live Stream, choose:

    Platform: MicroscopeMindQuality: Standard

    That's all. The picture comes in by itself, and from now on it does every time the app is open.

    Not ticking? Try these
    • Standard isn't listed: import the file again (the step before).
    • Choose Standard, not the app's own qualities: some of them close the app as it starts streaming.

All set. Next time, just open Blackmagic Camera on your iPhone and the picture appears here.
