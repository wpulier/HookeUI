This is scikit-image's `human_mitosis` image, human cells undergoing mitosis,
from Moffat et al., Cell 124(6):1283–98 (2006), doi:10.1016/j.cell.2006.01.040.

The original TIFF is preserved without modification as `human_mitosis.tif`.
`human_mitosis.png` is a lossless browser copy of the same 512 × 512 uint8 pixels.
No physical scale is supplied: measurements must use pixels.
