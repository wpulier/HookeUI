Hooke 0.1.2

- Available updates appear as a quiet Update control beside Settings. Review the release when you are ready.
- Settings includes your installed version and Check for updates.
- Update restart asks separately and defaults to Keep Working. Pending or conflicted Project notes and arrangements block restart.
- Saved Projects and scientific data remain outside the app. Restarting stops active work; unsaved tool edits, console variables and unsent messages may be lost. Save tool changes and finish or stop work first. Jobs and private tool sessions do not automatically resume.

Known limits

The full scientific workflow, independent package qualification and cross-platform qualification remain open. These update safeguards do not establish automatic saving of every plugin's state or resumability of every operation. See the release checks for exact tested behavior.
