# HookeUI Beta 0.2.3 — scientific workspace

This Beta brings imported scientific images, prepared tools, segmentation, saved corrections and measurements into the Mac workspace. Continue measurements into tables, analyses and graphs. Keep tool documents and explicitly saved results in the same Project. Saved Study drafts retain their inputs without starting research.

## Try the supported scientific route

1. Import the supplied reader, Cellpose and animation companion ZIPs in Models. Prepare, review and explicitly enable each tool. Unzip the supplied human_mitosis_crop.ome.zarr.zip and import its folder as a scientific input.
2. Inspect the saved image and axes, choose Cellpose, review settings and explicitly Run. Inspect masks, correct labels and Save tool. Keep original and alternative results available.
3. Open the saved correction, choose Measure and select cp_masks. Export native arrays and the object table. Open the measurements as an editable table; use Analyze or Graph on a saved revision.
4. Continue the saved scientific view into animation, edit keyframes and timing, export a movie and save its document. Explicitly save changes before quitting. Reopen the Project and its saved work.

## Scope and limitations

- The pinned 128 × 128 human-mitosis crop supports a bounded local workflow. It is a CC0 example, not biological ground truth or independent scientific qualification. Model output may vary slightly across runtime devices.
- Reader support is the declared uncompressed OME-Zarr subset. The 64 GiB admission ceiling is not a verified workflow capacity. A 9 GiB import was stopped safely when this verification Mac ran short of disk space; full large-volume processing remains unverified.
- Save tool retains accepted plugin state; unsaved changes remain drafts. Preview exports are presentation images; native export retains scientific values. Animation preserves supported camera/dimension keyframes.
- Preparing imported code requires explicit trust. If setup waits for permission, open the imported model’s details in Models and allow that publisher before continuing. Setup details contains diagnostics, not a complete streaming log.
- A stopped scientific review may report a cleanup warning even after its worker and reservation are released. Retained work remains available; reopening can recover.
- Study drafts and provider readiness are available. Actual Claude-managed research, Gemini tool use, GCP staging/GPU processing and cloud recovery are not qualified in this release. Unavailable connections must not be shown as ready. OpenAI access remains a follow-up. No hosted web app or sharing service is included.
- Will’s remaining installed continuous-use and owner acceptance stay separate. Prior camera/voice observations are not fresh acceptance of this candidate.

Beta uses its own bundled local backend and data. You choose when to install and restart. Stable remains unchanged until explicit promotion. The full continuation plan and Parts 2–3 remain open.
