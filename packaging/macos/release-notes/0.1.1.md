# Hooke 0.1.1

- Automatic update checks, with you in control of downloading and restarting.
- Existing beta installations can now update through HookeUI → Check for Updates….
- Saved Projects and scientific resources stay in your data folder when the app updates.

Save drafts and finish or stop active work before choosing Install and Relaunch. You can defer an update and keep working.

# Current limitations

This release connects updates to the October 19 scientific-workflow milestone. It does not complete the full napari parity or independent qualification program. The complete packaged scientific chain remains unqualified. Two recorded click-latency failures and the optional SAM 3.1 and Molmo preparation failures remain open. See the workflow guide and known issues on hookeui.org.
