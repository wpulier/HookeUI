# Reproducible examples

[Three particles](three-particles/README.md) generates and checks the synthetic
96 × 96 input for the first scientific journey, using the pinned Fiji fixture
recipe. No private recording, account or model is required. Generated files
stay outside the checkout; the recipe and provenance requirements live here.

[Published datasets](datasets/README.md) are `dataset.acquire` manifests, among them the three reference sources of
the VCC 2026 entry with each file's sha256 pinned from that night's downloads.
